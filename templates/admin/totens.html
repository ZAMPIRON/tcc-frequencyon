Como funciona
  1. Clique em Novo totem, dê um nome e escolha a sala. Aparece um código de ativação.
  2. No tablet da sala, abra {{ url_for('reconhecimento.pagina_totem', _external=True) }} e digite o código. Isso é feito uma vez só.
  3. Todo dia, um professor daquela turma libera o totem olhando para a câmera. Ele fica liberado até as 23:59.
  4. Para trocar o tablet, gere um código novo: quando o aparelho novo ativar, o antigo perde o acesso.
